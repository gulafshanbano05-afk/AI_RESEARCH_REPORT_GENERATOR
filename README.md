An autonomous multi-agent research orchestrator built with **LangGraph** and **Groq**. It gathers multi-source web and encyclopedic context, extracts core findings, generates structured outlines, synthesizes formal academic briefs, and enforces claim-verification loops to prevent hallucinations.
